# Taxonomía de feedback B2B

Una queja usa un solo módulo y una sola etiqueta. Si la confianza es menor a 70, no recibe etiqueta definitiva.

## Módulos

- `[Gestión de Vacantes]`
- `[Catálogo de Candidatos]`
- `[Solicitud de vacantes]`
- `[Creación de vacantes]`
- `[Carga Masiva de Perfiles]`
- `[Analítica / Superset]`
- `[Bot omnicanal]`

## Etiquetas

- `[BUG]`: la pantalla falla, no carga o impide continuar.
- `[UX/Usabilidad]`: hay fricción o algo cuesta de encontrar, y el flujo igual se puede terminar.
- `[PERFORMANCE]`: la espera o la lentitud es el problema.
- `[FEATURE]`: piden una capacidad que hoy no existe.

## Criticidad

El mismo comentario normalizado del mes es un hallazgo. El color lo calcula el conteo dividido por las preguntas abiertas que entran a tipificación. Ni el modelo ni la Líder UX lo eligen.

- `verde`: hasta el 20 % inclusive.
- `amarillo`: más del 20 % y hasta el 50 % inclusive.
- `rojo`: más del 50 %.
